Heutrix Diagnostics is a standalone paid decision product. It should remain useful if the client does not buy implementation.

The [integrated architecture](../../02-market-and-offers/offers/offer-strategy-2026-09/06-integrated-offer-architecture.md) now defines the working core decision pack, investigation boundary and completion test. Validate coverage, effort and acceptance before contracting. A no-build conclusion is a valid result; the pack should document evidence limits and an actionable next step. This refinement does not reissue the legacy pack below.

The existing [operations pack](operations-pack-v1/) contains fit-call and pre-rebrand Workflow Diagnostic working documents, native files, spreadsheets, slides, QA renders and a packaged release. It predates the 3 September 2026 decisions and is **not a current operating master**.

The consistency review found 30-minute/free-booking wording, the retired “Workflow Diagnostic” name, a fixed AUD 950 fee and then-unverified entity wording in the native pack. Do not issue, quote from, train from or regenerate its ZIP until the pack is reissued using:

- **Heutrix Diagnostics**;
- the intended 20-minute call and request-mode language until direct scheduling works;
- no public price, with the private fee taken only from an approved written scope; and
- verified business particulars and approved legal/delivery rules.

The workbook and findings deck remain useful draft structures, but all client-facing text and commercial assumptions require the same reconciliation and approval.

A complete Diagnostic should define the problem and workflow boundary, current state, baseline or baseline plan, ranked bottlenecks and risks, feasible options including no-build, recommended future state, draft measures/acceptance criteria and a decision-ready next scope.
