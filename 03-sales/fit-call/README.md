# Fit call

The approved end state is a directly bookable 20-minute workflow fit call. The current mechanism is still request mode because the scheduler, lead destination and receipt path are not yet evidenced as live and tested. Use **See where Heutrix can help** publicly and **Request my 20-minute call** on the form until those gates close. Use the [detailed call guide](SALES-PROCESS-SPECIFICATION.md) as the working draft until it is approved here.

Before launch, confirm the caller, backup, calendar, availability, no-show/cancellation rules, qualification authority and follow-up service levels. The call is for fit and routing, not unpaid consulting or the collection of sensitive operational detail.

Use the [integrated offer architecture](../../02-market-and-offers/offers/offer-strategy-2026-09/06-integrated-offer-architecture.md) for the refined routing conditions: Diagnostics for uncertainty, direct Transformation when one workflow can be scoped and tested, and AI Guardrails for workplace AI governance. These are independent entry points with delivery prerequisites, not a required sequence. Reuse approved Diagnostic artefacts; do not imply an automatic fee credit.

The 5 September comparison-site decision uses **Request a free consultation**, retaining the 20-minute fit boundary. Preserve the relevant site's actual request mechanism and do not describe a request or mock submission as a confirmed booking. See the [decision register](../../00-control/DECISIONS.md).
