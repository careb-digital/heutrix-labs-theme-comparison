# Proposals

Create proposals only from approved offer, pricing, legal and delivery rules.

Every proposal should define the workflow boundary, current problem, controllable result, assumptions, client commitments, deliverables, acceptance criteria, exclusions, dependencies, information handling, ownership/handover, price, payment stages, change triggers and expiry.

Do not quote a system integration or regulated outcome before feasibility and responsibility have been confirmed in writing.
