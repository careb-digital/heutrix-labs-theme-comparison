# P2 — Build high-intent lead magnets

**Recommended environment:** ChatGPT Work for strategy/content, then Codex for implementation  
**Priority:** Post-launch optimisation  
**Start when:** Offer, conversion path and proof demonstration are working.

## Copy this prompt into a new chat

```text
Act as Heutrix Labs' lead-magnet strategist and implementation lead. Work inside the current Heutrix repository. Read the control registers, approved offer and current lead-magnet release register first; use Phase 8 and the lead-generation recommendations in HEUTRIX-LABS-LAUNCH-REVIEW.md as historical context.

Goal: create lead magnets that solve problems the target buyer already wants solved and naturally qualify prospects for Heutrix Diagnostics, Heutrix Workflow Transformation or Heutrix AI Guardrails. Do not create a generic newsletter.

Evaluate and prioritise these three concepts:
1. Workflow Bottleneck Scorecard for allied health/disability operations leaders.
2. Referral-to-First-Appointment Workflow Map for allied health practices.
3. Heutrix AI Guardrails Admin Starter Pack for care teams using or considering AI.

For each, define target segment/role, urgent problem, promised quick win, input effort, format, data collected, qualification signal, CTA and paid-service bridge. Score each on demand relevance, differentiation, production effort, proof required and lead quality. Select one to build first.

Build the selected asset end to end:
- Useful content/tool with specific, actionable output.
- Landing page and outcome-led CTA.
- Minimal privacy-conscious form; do not collect patient/participant information.
- Delivery method and confirmation/follow-up sequence.
- Source/UTM and CRM tagging.
- Natural next step based on result, without fear tactics or fake urgency.
- Accessibility, mobile, analytics and production test plan.

For a scorecard, show how scoring is derived and avoid presenting it as a compliance, legal, clinical or security assessment. For Heutrix AI Guardrails content, use cautious operational guidance and identify where professional review is needed.

Do not invent benchmarks, regulatory conclusions, expected savings or conversion rates.

Deliverables:
- Three-concept prioritisation table.
- Complete first lead magnet and copy.
- Delivery/nurture specification and implementation where authorised.
- Measurement plan: visitor → completion → qualified lead → booking → customer.
- Backlog for the remaining two concepts.

Definition of done: the chosen asset creates stand-alone value, attracts the intended decision-maker, captures only necessary information, is accurately delivered and leads logically to a paid diagnostic or fit call.
```
