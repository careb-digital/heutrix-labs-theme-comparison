# Applications

- [`website/`](website/) — canonical local public-site application. Local implementation and technical verification do not constitute owner approval or live publication.
- [`internal-reports/`](internal-reports/) — internal audit and analysis sites kept separate from the public application.

Run and deploy each application from its own directory. Do not assume package commands at the repository root.
