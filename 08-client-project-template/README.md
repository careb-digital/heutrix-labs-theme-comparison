# Client project template

This is a reusable engagement structure only. **Do not store a live client's identifiable, health, participant, worker, credential, payment or other sensitive information in this Git repository.**

When onboarding is approved, copy this structure into the approved secure client-work system and apply the engagement's access, retention and deletion rules.

## Stage gates

1. `01-contract/` — signed authority, scope, data schedule and start conditions.
2. `02-client-inputs/` — controlled source materials and access register.
3. `03-working-papers/` — discovery, maps, decisions and test evidence.
4. `04-draft-deliverables/` — controlled review versions.
5. `05-issued-deliverables/` — accepted/issued versions and handover.
6. `06-closeout/` — acceptance, access removal, retention/deletion and lessons.

## Shared maintenance
Delivery is the responsible workstream; the person remains unassigned in the [role register](../01-company/founders-and-roles/ROLE-REGISTER.md#folder-ownership). Record template changes in [Delivery's changes index](../04-delivery/changes/README.md). Review contract/start changes with Sales and Legal and follow the [shared workflow](../00-control/COLLABORATION.md). Keep synthetic rehearsal evidence separate from a live engagement.
