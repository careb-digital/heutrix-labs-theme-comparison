## Upload

Start with **jpg/heutrix-linkedin-company-navy-centred-1512x256.jpg**. Use the light version for a pale background. Choose a compact version when the Page preview crops more tightly. Upload to the **company Page cover**, not a personal profile background or a Life-tab image.

All eight upload files are exactly **1512 × 256 pixels**, between 19 KB and 53 KB, below LinkedIn's 3 MB limit. High-quality JPEGs use quality 98 and 4:4:4 colour sampling. PNG alternatives and SVG masters are included. SVG is an editing master, not a LinkedIn upload format.

The logo is centred with generous margins rather than positioned towards the right. Compact versions use a smaller logo to tolerate tighter crops. The supplied logo paths, proportions and approved palette remain unchanged.

Preview desktop and mobile after uploading and adjust positioning if needed. Actual LinkedIn rendering has not been tested in the account; LinkedIn can crop and recompress uploads.

[LinkedIn's current official Page guidance](https://www.linkedin.com/help/linkedin/answer/a570368), checked 15 September 2026, recommends 1512 × 256, PNG/JPEG under 3 MB, high-quality JPEG for resolution, and central placement away from edges. The earlier pack used 4200 × 700 from stale search results. Its files and documentation remain intact as requested; use this v2 set for the company Page.
