## P14 — What useful workflow maps reveal

**Format:** Six images. Submit the full prompt six times, changing only `TARGET PAGE` from 1 to 6.

```text
TARGET PAGE: 1

Create exactly one page—the TARGET PAGE only—of a six-page LinkedIn explainer for Heutrix, an Australian workflow-improvement business. The audience is decision-makers at disability support providers first and allied-health practices second. The purpose is to show that a useful workflow map reveals behaviour, ownership, information, decisions, exceptions, waiting and closure rather than merely drawing task boxes. Do not produce a contact sheet, dense swimlane chart or multiple images.

Make the page 1080 × 1350 px, 4:5 portrait. Use near-white #F8FAFC, logo navy #033862, slate #334155, border grey #E2E8F0, teal #01989C and pale teal #EFFAFA with deep teal #01647C text only for the key decision or finish. Use geometric sans-serif headings similar to Plus Jakarta Sans, clean sans-serif body similar to Inter, high contrast, generous whitespace, one recurring simple workflow line, line icons, 8 px cards, 1 px borders, subtle shadows and 60 px margins. Add a target-matching page marker. Use bright teal only decoratively; use navy or deep teal for text on light surfaces. Leave an unlabelled logo area; do not create a logo.

Render the selected page:
- Page 1: “A workflow map should explain how the work behaves.” Add “Task boxes are not enough.”
- Page 2: “Ownership”. Questions: “Who owns each action?” and “Who accepts the handover?” Show role icons attached to steps.
- Page 3: “Information”. Questions: “What is needed?” and “Where should it live?” Show one protected source record and one minimal operating reference.
- Page 4: “Decisions and exceptions”. Questions: “What changes the path?” and “What happens when information is missing?” Show a decision diamond and visible exception loop.
- Page 5: “Waiting and closure”. Questions: “Where does work wait?” and “What counts as done?” Show a review-date marker and explicit close outcomes.
- Page 6: “A future state makes choices”. List “Remove a step”, “Clarify a handover”, “Expose a status”, “Keep a decision human”, “Avoid unnecessary copying”. End with “The value is not drawing boxes. It is deciding how work should operate.”

Use only the exact copy assigned to the target page and its page marker. Do not show people receiving care or support, real records, system logos, prices, metrics, results, compliance marks, robots or futuristic interfaces. Keep every word sharp and phone-readable.
```

**Alt text draft:** Six-page document showing ownership, information, decisions, exceptions, waiting and closure as the elements a useful workflow map should reveal.
