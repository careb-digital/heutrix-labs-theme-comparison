## P02 — Five workflow questions

**Format:** Five images. Submit the full prompt five times, changing only `TARGET PAGE` from 1 to 5.

```text
TARGET PAGE: 1

Create exactly one page—the TARGET PAGE only—of a five-page LinkedIn document for Heutrix, an Australian workflow-improvement business. The audience is decision-makers at Australian disability support providers first and allied-health practices second. The purpose is to help them define a workflow before buying technology. Do not create a contact sheet, collage, PDF preview or more than one image.

Make the page 1080 × 1350 px, 4:5 portrait. Use the same repeatable visual system on every possible target page: near-white #F8FAFC, logo navy #033862, slate #334155, border grey #E2E8F0, teal #01989C and pale teal #EFFAFA with deep teal #01647C text only for the final or most important action; bold geometric sans-serif headings similar to Plus Jakarta Sans; clean sans-serif body similar to Inter; generous whitespace; simple line icons; 8 px cards; 1 px borders; subtle navy shadows; high contrast; minimum 60 px margins. Use a thin five-step vertical path as the recurring motif. Add a small page marker matching the target, such as “1 / 5”. Leave a clean unlabelled top-right logo area; do not invent a logo.

Render the selected page from this exact page map:
- Page 1: “Before buying another tool, answer five workflow questions.” Show a simple tool icon held outside a five-step path.
- Page 2: “1. Trigger — What starts the work?” and “2. Owner — Who owns the next action?” in two stacked cards.
- Page 3: “3. Information — What is needed, and where should it live?” and “4. Exception — What happens when the normal path breaks?” in two stacked cards.
- Page 4: “5. Finish — What does done mean, and who confirms it?” Show a clear end marker paired with a named-role icon, not a tick alone.
- Page 5: “Unclear workflow + new technology = faster confusion.” Below it, show six equal chips: “Simplify”, “Clarify”, “Track”, “Automate”, “Build”, “No build”.

Use only the exact copy assigned to the selected page plus its page marker. Do not add explanations or filler. Do not show branded software, robots, AI brains, people receiving support or care, client information, prices, statistics, testimonials or claims. Keep all words sharp and phone-readable.
```

**Alt text draft:** Five-page document explaining the trigger, owner, information, exception and finish questions to answer before choosing technology.
