## Source boundaries
The detailed Sales process now lives under Sales. Marketing's former file is a navigation pointer. Marketing continues to own page copy and campaigns, while Sales controls operating qualification, booking, CRM and handoff requirements. The combined specification includes interface wording for that journey; page-level copy should link to it and implement the same mechanism.

The pre-reconciliation native fit-call playbook in the Delivery pack remains a quarantined draft, not a second current Sales master. Moving the text specification does not approve or reissue that pack.

## For every shared change
List the source rule, consuming folders, proposed effect, responsible reviewers and whether all consumers must change together in the task brief. A source-only correction can explain why consumers need no update. A changed promise must not enter the master while a dependent current asset contradicts it.
