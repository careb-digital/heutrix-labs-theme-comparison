## Ten prompts

Run one prompt per outcome-focused chat. The heading provides a suggested chat title. Each prompt uses this Project's instructions and sources. Complete dependent owner decisions before treating the resulting drafts as approved or live.

### 02-01 | Tighten the sourcing profile

Translate the approved ideal client profile into an internal prospect-screening rubric based on funded workflow volume, cross-role complexity, accountable owner, access and budget seriousness. Avoid unsupported public headcount thresholds. Include clear fit, uncertain-fit and no-fit examples.

### 02-02 | Resolve offer contradictions

Compare the flagship specification, comparison and validation register. Identify tensions involving 2–4 weeks, 30-day stabilisation, prerequisites, budget language and delivery limits. Produce a source-cited reconciliation table and owner questions, without weakening approved boundaries.

### 02-03 | Make one workflow measurable

Draft an internal scoping worksheet for Workflow Transformation covering roles, systems, integrations, views, measures, forms, automation steps, permissions and review rounds. Provide one synthetic intake example and explicit exclusion/change triggers.

### 02-04 | Define the product routing decision

Create a practical routing guide for Diagnostics, direct Workflow Transformation, AI Guardrails and no project. Use buyer readiness and uncertainty, not the resource downloaded. Include cases where an existing vendor feature or no-build option is preferable.

### 02-05 | Build a capability evidence register

List the tool and integration capabilities mentioned in the offer sources. Classify each as evidenced, unverified or proposed. Define the demonstration, access, licensing and technical evidence required before Sales or Marketing can promise it.

### 02-06 | Design buyer validation interviews

Prepare a non-leading interview guide testing workflow pain, current alternatives, budget authority, procurement, urgency and willingness to pay. Separate discovery from selling and free interest from purchase evidence. Request only non-sensitive operational descriptions.

### 02-07 | Turn market-fit research into a test

Convert the September 5 market-fit proposal into an owner-reviewable experiment. Preserve current public positioning. Define comparable disability/allied-health/challenger cohorts, channel controls, evidence thresholds and reasons the result could remain inconclusive.

### 02-08 | Test the customer value case

Create a value-case worksheet using buyer-supplied baseline volume, time, errors and costs. Show conservative ranges and total ownership cost. Keep estimates separate from measured results; do not infer future savings from the case-study collection.

### 02-09 | Define a genuinely smaller scope

If a suitable buyer cannot fund the standard implementation, design a smaller bounded deliverable by removing effort and dependencies. Compare inclusions, exclusions and buyer value with the full offer. Send effort assumptions to Finance; do not invent an approved price.

### 02-10 | Set evidence rules for scaling

Draft a decision memo defining evidence required before changing segment priority or increasing sales volume. Cover completed comparable paid work, actual labour, acquisition effort, collection, acceptance and remaining defect obligations. Label proposed thresholds as management choices.
