# Founder collaboration
**Updated:** 5 September 2026. Janith coordinates merges; [folder owners](../01-company/founders-and-roles/ROLE-REGISTER.md#folder-ownership) remain unassigned.

## Start and work
Follow [AGENTS.md](../AGENTS.md), the relevant folder README and the task source. Do not read every control file for a routine edit. Use [dependencies](DEPENDENCIES.md) and relevant decision/fact entries only when changing shared rules.

Each founder uses a separate clone and a short branch from current shared `main`. Refresh during active work and before integration. Janith allocates tasks while permanent owners are unassigned. Keep existing subject paths and one authoritative source; do not create founder-specific master copies.

## One work record
A review request or task handoff is enough for a small change. Use [a dated brief](templates/CHANGE-BRIEF.md) and the folder's `changes/` index only for multi-founder, multi-day or cross-folder work. Do not maintain the same plan in both places. Record outcome, changed sources, checks, dependencies and required sign-off.

## Review and integrate
Use the [merge checklist](templates/MERGE-CHECKLIST.md). An independent reviewer checks the change; affected responsible people review shared scope, pricing, timeline, claim, contract or data decisions. Janith coordinates the merge, including another reviewer for his own work. Refresh dependent working copies afterwards. Silence is not approval; revert mistakes through a reviewed correction, not a wholesale folder overwrite.

Native Office masters have one acknowledged editor in [FILE-EDIT-REGISTER.md](FILE-EDIT-REGISTER.md). Rebuild and validate affected exports/distribution copies from that master. Merging does not approve publication, quoting, legal use or onboarding.

## Setup and exceptions
Before another computer clones, complete [the shared baseline checklist](COLLABORATION-SETUP.md). It remains open; local files and templates do not configure remote permissions.

If a folder must be exported, preserve relative paths and include only required shared context, a base commit and changed-file record. Treat context copies as reference-only. Janith compares base, returned work and current master before integration. Never overwrite the master with the returned folder.
