# Merge checklist
Use in each review request. Janith coordinates integration; this checklist does not grant business or publication approval.

- [ ] Author, folder, base commit and change brief are identified.
- [ ] Branch incorporates the latest shared main and conflicts are resolved.
- [ ] Changed files match the task; unrelated work is preserved.
- [ ] Current decisions and facts were checked; proposed rules are visibly proposed.
- [ ] All affected areas are listed; their required sign-offs include names, dates and evidence.
- [ ] An independent reviewer checked the change; Janith's own work is not self-approved.
- [ ] Current masters, generated outputs and distribution copies agree where affected.
- [ ] Links and navigation resolve; moves are recorded in the move manifest.
- [ ] Applicable document/model/application checks passed, with results recorded.
- [ ] No prohibited sensitive data, secrets, incidental runtimes or unintended nested repositories are included.
- [ ] Decisions, facts, risks and launch status are updated when warranted.
- [ ] Native-file reservations are released after handoff.
- [ ] Change brief and task index have the integration reference; dependent founders are told to refresh.
