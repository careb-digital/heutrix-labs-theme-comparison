# Interactive resources

Route: `/resources`.

Start with a clearer picture. Work through one operational question. Get a useful result, save it for your team, or bring it to a conversation with Heutrix.

- **Workflow Bottleneck Scorecard:** Find the workflow worth improving first.
- **Enquiry-to-Service-Start Planner:** See where enquiries stall.
- **AI Guardrails Check:** Give AI use a clear review path.

Each tool offers a personalised result, action plan download, summary copy, clean share link and relevant consultation path. The existing PDF/workbook pair remains downloadable. No account is required. Answers stay in page memory unless the visitor chooses to share a summary.

These tools support operational thinking. They are not tailored advice, organisational approval or an assurance of compliance. See [the implementation guide](../../apps/website/LEAD-MAGNETS.md) for rules, handoffs and tests.
